KHYLO SERVER FOR WINDOWS: PORTABLE VERSION
==========================================

This is the "just run it" version of Khylo. Nothing is installed: no startup entry, no firewall changes.
If you want Khylo to start with Windows and keep running, use the installer instead
(khylo-server-<version>-windows-<cpu>-setup.exe, from the same download page).

TO RUN IT
   1. Right-click this zip and choose Extract All.
   2. Double-click Start-Khylo.bat.
   3. When it says it is listening, open http://localhost:8096 and follow the setup.
   4. Close the window to stop Khylo.

WHERE THINGS ARE
   Library, users, settings:  %LOCALAPPDATA%\Khylo   (back this folder up)

NOTES
   Windows may ask once whether to allow Khylo through the firewall. Choose Private networks.
   If Windows shows "Windows protected your PC", choose More info, then Run anyway.
